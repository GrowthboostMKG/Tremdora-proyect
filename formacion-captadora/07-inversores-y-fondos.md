# Módulo 07 · Estructura para trabajar con inversores y fondos (incluidos los "fondos buitre")

> **Estatus en este módulo**: habla el idioma del inversor (rentabilidad, repercusión, plazos, riesgo), responde en 24 horas y nunca improvises una cifra. Lleva solo lo que encaja con su tesis: un filtro exigente hace que confíen en todo lo que envías.

> Con inversores y fondos **las reglas cambian**: no compran emociones, compran **números,
> rapidez y seguridad jurídica**. Si les traes producto bien presentado y les ahorras tiempo,
> te convertirás en una proveedora a la que llaman primero.
>
> Nota de vocabulario: "fondo buitre" es un término coloquial (a veces despectivo) para
> **fondos oportunistas o *distressed***: compran con fuertes descuentos activos con
> problemas (deuda, ocupación, cargas, carteras de bancos). En la conversación profesional
> usa "fondo oportunista", "fondo *value-add*" o "inversor institucional".


> **Continúa en el [módulo 26](26-inversores-vender-negociar-ser-referente.md)**: cómo vender producto a inversores paso a paso (con caso de inversión numérico), negociar con ellos, el trato profesional que esperan y cómo convertirte en su proveedora de referencia para proyectos.

## 1. Mapa de compradores profesionales

| Tipo | Ticket típico | Qué busca | Velocidad | Cómo llegar |
|---|---|---|---|---|
| **Pequeño inversor particular** | 60.000–400.000 € | Pisos para alquilar (yield bruta 5–8 %), reforma y venta | Media | Redes, base de la agencia, referidos, eventos |
| **Inversor profesional / "flipper"** | 100.000–1 M€ | Pisos a reformar con descuento, divisiones horizontales, locales a vivienda | Alta | LinkedIn, clubs de inversión, grupos de reformistas |
| **Family office** | 1–20 M€ | Edificios enteros, locales prime, activos con renta estable | Media | Asesores patrimoniales, abogados, eventos del sector |
| **SOCIMI / patrimonialista** | 2–50 M€+ | Activos con renta (residencial, retail, oficinas) y gestión fácil | Lenta (comités) | Departamentos de inversión, consultoras |
| **Fondo *value-add*** | 5–100 M€ | Edificios para reposicionar, *build to rent*, *coliving*, residencias | Media | Consultoras, brokers institucionales, LinkedIn |
| **Fondo oportunista / *distressed* ("buitre")** | 1 M€–cientos de M€ | Carteras REO/NPL, ocupados, activos con cargas, edificios con problemas, compras con descuento del 30–60 % | Muy alta si el precio encaja | Servicers, abogados de reestructuración, subastas |
| **Servicers** (gestoras de activos de banca/fondos) | — | **Venden** (y a veces compran) activos adjudicados | — | Plataformas y redes de colaboradores (API) |

> **Servicers** relevantes en España: gestionan los inmuebles de bancos y fondos
> (adjudicados, recuperados). Muchos tienen **programas de colaboradores/APIs** para
> agencias. Pregunta a tu agencia si estáis dados de alta. Son la principal **fuente de
> producto** para inversores *distressed*.

## 2. Tipos de producto que mueve este mundo

| Producto | Qué es | Quién compra |
|---|---|---|
| **Vivienda con inquilino** | Se vende con contrato en vigor | Pequeño inversor, patrimonialista |
| **REO** (*Real Estate Owned*) | Inmueble ya adjudicado al banco/fondo | Inversor particular y profesional |
| **NPL** (*Non-Performing Loan*) | Se compra el **crédito hipotecario impagado**, no el inmueble | Fondos *distressed*, inversores sofisticados |
| **Cesión de remate** | Derecho a adjudicarse un inmueble en una subasta ya celebrada | Inversores especializados |
| **Subasta judicial / AEAT / Seguridad Social** | Portal de Subastas del BOE | Inversores especializados |
| **Ocupado / sin posesión** | Inmueble con ocupantes sin título | Fondos e inversores especializados (descuentos altos) |
| **Edificio completo** | Un único propietario o comunidad que vende en bloque | Family office, fondos, patrimonialistas |
| **Local con cambio de uso a vivienda** | Locales en planta baja convertibles (según ordenanzas) | Inversores profesionales |
| **Suelo / solar** | Con o sin licencia | Promotoras, fondos |
| **Nuda propiedad** | Se compra la propiedad sin el uso (el usufructuario sigue viviendo) | Inversores a largo plazo |
| **Cartera** | Varios activos en bloque (decenas o cientos) | Fondos |

## 3. Tu estructura de trabajo con inversores (8 fases)

```
1. Captar inversores → 2. Cualificar (KYC + perfil) → 3. Proteger tus honorarios
→ 4. Buscar/captar producto → 5. Presentar (teaser → IM) → 6. Oferta / LOI
→ 7. Due diligence → 8. Cierre y postventa
```

### Fase 1 · Captar inversores
- LinkedIn (perfil profesional, contenido sobre rentabilidades en tu zona).
- Clubs y foros de inversión inmobiliaria, eventos del sector (ferias, jornadas de inversión).
- Asesores financieros, abogados, gestorías, brokers hipotecarios.
- Base de datos de la agencia (compradores que preguntaron por rentabilidad).
- Cada vez que captes un producto "de inversor", es tu excusa para contactar a nuevos inversores.

### Fase 2 · Cualificar al inversor — Ficha de inversor (obligatoria antes de enviar nada)

| Campo | Ejemplo |
|---|---|
| Nombre / sociedad / titular real | |
| Tipo (particular, family office, fondo…) | |
| Decisor real (¿hablas con quien firma o con un intermediario?) | |
| Producto que busca | Pisos con inquilino, edificios, ocupados… |
| Zonas | |
| Ticket mínimo y máximo | |
| Rentabilidad exigida (bruta/neta, TIR) | |
| Estado aceptado | A reformar / ocupado / con inquilino |
| Financiación | Fondos propios / hipoteca preaprobada / financiación del fondo |
| **Prueba de fondos (POF)** | Certificado bancario o carta del fondo |
| Plazo de decisión | |
| Honorarios aceptados | ¿Paga el comprador? ¿El vendedor? ¿Ambos? |
| **KYC / PBC** completado | Sí/No (módulo 01 §2) |
| Operaciones cerradas anteriormente | |

**Clasifica**: A (fondos verificados, decide rápido), B (interesado serio sin POF todavía),
C (curioso / intermediario sin mandato). **Solo envías producto off-market a A y B.**

> 🚩 **Cuidado con las cadenas de intermediarios**: "tengo un fondo que compra todo" sin
> nombre, sin mandato y sin POF. Exige siempre: identidad del comprador final o un
> **mandato firmado** del intermediario con su cliente.

### Fase 3 · Proteger tus honorarios (ANTES de revelar información)
1. **Hoja de encargo del vendedor** firmada (si representas al vendedor).
2. **Encargo de búsqueda** firmado por el inversor (si representas al comprador), con
   honorarios acordados (habitual: 2–3 % + IVA o fijo, según operación).
3. **NDA / acuerdo de confidencialidad** antes de dar la dirección o documentación.
4. **Acuerdo de no elusión (*non-circumvention*)**: el inversor se compromete a no negociar
   directamente con el propietario a tus espaldas durante un periodo (12–24 meses).
5. **Registro de presentación**: email al inversor con el activo presentado, fecha y su
   respuesta. Es tu prueba si después compra sin ti.
6. Si colaboras con otra agencia: **acuerdo de colaboración** (reparto de honorarios por escrito).

### Fase 4 · Buscar o captar producto para inversores
- **Propietarios particulares** que quieren discreción o rapidez (herencias, deudas, cansados
  de alquilar) → venta off-market.
- **Comunidades/propietarios únicos de edificios** (los administradores de fincas saben cuáles).
- **Servicers** (alta como colaboradora) para REO.
- **Abogados** (concursos de acreedores, liquidaciones, herencias complejas).
- **Portal de Subastas del BOE** y edictos (para inversores especializados).
- **Locales vacíos** en tu zona: localiza al propietario por nota simple y contacta por carta
  (no por teléfono).

### Fase 5 · Presentar el producto
1. **Teaser** (1 página, **anónimo**: sin dirección exacta): tipo de activo, zona, m², estado,
   renta actual, precio, rentabilidad, puntos fuertes, riesgos principales.
2. Si muestra interés → **NDA firmado** → **Information Memorandum (IM)** o dossier completo:
   - Dirección, nota simple, catastro, planos, fotos.
   - Contratos de alquiler y rentas (*rent roll*), estado de pagos.
   - Gastos (IBI, comunidad, seguros), CEE, ITE.
   - Situación posesoria (libre, alquilado, ocupado) y procedimientos judiciales si hay.
   - Cálculo de rentabilidad (bruta, neta) y escenario *value-add* (reforma, subida de rentas
     al vencimiento, división).
3. **Data room** (carpeta compartida con permisos) para operaciones grandes.
4. Visita (si es posible; en ocupados, a menudo solo exterior).

> **Sé honesta con los riesgos.** Un inversor profesional los va a encontrar en la *due
> diligence*. Si los ocultas, pierdes al inversor para siempre. Si los muestras, ganas su confianza.

### Fase 6 · Oferta y carta de intenciones (LOI)
- Oferta **por escrito**: precio, condiciones (sujeta a *due diligence*, a financiación…),
  plazo de exclusividad de negociación (2–6 semanas), plazo de cierre, depósito/arras.
- La **LOI** suele ser no vinculante salvo exclusividad, confidencialidad y gastos.
- Tu papel: traducir la oferta al propietario con su **neto** y **riesgos**, y negociar.

### Fase 7 · Due diligence (revisión del activo)
| Área | Qué se revisa |
|---|---|
| **Legal/registral** | Titularidad, cargas, servidumbres, procedimientos, licencias |
| **Urbanística** | Calificación, usos permitidos, edificabilidad, infracciones, protección |
| **Técnica** | Estado del edificio, estructura, instalaciones, ITE, accesibilidad |
| **Arrendaticia** | Contratos, rentas, fianzas depositadas, impagos, prórrogas, vulnerabilidad |
| **Fiscal** | IBI, plusvalía, tributación de la operación (ITP vs. IVA) |
| **Ambiental** | Amianto, contaminación de suelos (en suelos/industrial) |

Tu trabajo: **conseguir la documentación rápido** y tener un checklist (módulo 09).

### Fase 8 · Cierre y postventa
- Arras o contrato privado → escritura.
- Factura de honorarios según lo firmado.
- Ofrécete para la **gestión posterior**: alquiler de unidades vacías, venta de pisos tras
  reforma (*exit*), búsqueda de siguiente activo. **Un inversor bien atendido repite.**

## 4. Cómo negociar con fondos (especialmente *distressed*)

1. **Ellos tienen un modelo**: precio máximo = valor de salida − costes − margen exigido
   (a menudo TIR del 15–25 % en *distressed*). Pregunta: *"¿Con qué precio de salida y qué
   plazo estáis modelizando?"* Así entiendes su oferta.
2. **Primeras ofertas muy bajas son normales.** No te ofendas ni lo tomes como definitivo:
   contraargumenta con datos (testigos, rentas de mercado, plazos reales de desalojo/reforma).
3. **Crea competencia**: presenta el activo a 3–5 compradores cualificados con un plazo de
   ofertas (*proceso competitivo*). Es la mejor forma de proteger al vendedor.
4. **Velocidad y certeza valen dinero**: un vendedor que necesita liquidez puede preferir
   menos precio con cierre en 30 días y sin condiciones. Ponlo en la balanza con él.
5. **Todo por escrito**, con plazos.
6. **No cedas tus honorarios** al final por presión: están firmados en la fase 3.
7. **Protege al vendedor vulnerable**: si un propietario mayor, endeudado o en una situación
   personal difícil va a vender a un fondo con mucho descuento, asegúrate de que entiende el
   precio de mercado y sus alternativas, y recomiéndale asesoramiento independiente. Tu
   reputación (y tu tranquilidad) valen más que una comisión.

## 5. Números que debes dominar

| Indicador | Fórmula | Uso |
|---|---|---|
| Rentabilidad bruta | Renta anual / precio | Filtro rápido |
| Rentabilidad neta | (Renta − gastos) / (precio + costes de compra + reforma) | Comparar activos |
| *Cap rate* | NOI / valor | Valorar activos con renta |
| Cash-on-cash | Flujo de caja anual / capital propio invertido | Inversor con hipoteca |
| TIR | Tasa que iguala flujos futuros a la inversión | Fondos, horizontes 3–7 años |
| Descuento sobre mercado | 1 − (precio / valor de mercado libre) | *Distressed* / ocupados |
| Precio por unidad / m² | Precio / nº viviendas o m² | Edificios |

### Ejemplo rápido (vivienda con inquilino)
- Precio: 180.000 € · Renta: 900 €/mes (10.800 €/año).
- Bruta: 10.800 / 180.000 = **6,0 %**.
- Gastos anuales: IBI 450 + comunidad 900 + seguro 250 + mantenimiento/vacío 800 = 2.400 €.
- Costes de compra (ITP 7 % + notaría/registro ~1,5 %) ≈ 15.300 € → inversión total 195.300 €.
- Neta: (10.800 − 2.400) / 195.300 = **4,3 %**.

## 6. Fiscalidad y estructura que conviene conocer (nivel básico)

- **Compra de segunda mano**: ITP (según CCAA). **Compra a empresa con renuncia a la exención
  de IVA** (posible entre empresarios en ciertos casos): IVA con inversión del sujeto pasivo
  + AJD. Lo decide el asesor fiscal, pero conviene saber que existe.
- **Sociedad vs. persona física**: el inversor puede comprar a través de sociedad (Impuesto
  de Sociedades) o a título personal (IRPF; reducciones por alquiler de vivienda habitual del
  inquilino según la Ley 12/2023 y su régimen transitorio).
- **No residentes**: IRNR por rentas, retención del 3 % en la venta, NIE obligatorio, y
  normativa de inversión extranjera en algunos casos.
- **Gran tenedor**: si el inversor supera el umbral, tendrá obligaciones adicionales (en zonas
  tensionadas, límites de renta, y requisitos previos en procedimientos de desahucio relativos a
  la situación de vulnerabilidad del inquilino).
- **Golden Visa por inversión inmobiliaria**: **eliminada desde abril de 2025**.

> Siempre: *"Esto lo debe confirmar tu asesor fiscal; yo te doy el marco para que tengas las
> preguntas correctas."*
